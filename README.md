Task 2 – 3D CAD Model: L-Shaped Mounting Bracket

Project Overview

This project contains a 3D CAD model of a simple L-shaped mounting bracket designed as a small mechanical fixture.

The model demonstrates basic 3D CAD concepts such as creating rectangular features, maintaining specified dimensions, and preparing a model for 3D printing.

Model Specifications

- Model: L-Shaped Mounting Bracket
- Overall dimensions: 80 × 40 × 40 mm
- Material: Mild steel (conceptual)
- Plate thickness: 5 mm
- File format: STL
- Application: Mechanical mounting/support fixture

Files Included

- "task2_mounting_bracket.stl" – 3D model file
- CAD screenshots – Model views and documentation

Design Objective

The objective of this task is to create a simple mechanical component that can be used as a mounting/support bracket. The design is intended to demonstrate fundamental CAD modeling skills and produce a model suitable for further development or 3D printing.

Success Criteria

- Correct overall dimensions
- Clean and recognizable L-bracket geometry
- Exported successfully as an STL file
- Model can be opened in a compatible 3D/CAD application

Tools

The model was prepared as part of Task 2 – 3D CAD Modeling.
